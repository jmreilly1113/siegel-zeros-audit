\section{Threats to validity}\label{sec:threats}

\paragraph{Kernel trust.}
Comparator's README states its guarantees under six assumptions, among them that ``The Lean kernel is correct (with `external\_kernels` this can be reduced to "At least one of the Lean kernel or the `external\_kernels` is correct")''. % v12:L137
By Comparator's and lean4export's READMEs, both kernel checks depend on the same Lake build and the same lean4export export, while only the Lean kernel's check runs inside the Comparator process. % v12:L142
Two kernels therefore reduce the risk of a kernel bug but not of an exporter or build bug. % v12:L263

\paragraph{What agreement does not test.}
Our replay agrees with an independent replay on all 402 configurations where both have a verdict. % v12:L141
Every outcome on both sides of that comparison was acceptance, so the comparison does not test rejection. % v12:L264
Rejection is tested by negative controls. % v12:L034 v12:L035 v12:L260
The standalone nanoda check rejects the Lemma 3 export with Classical.choice not permitted (exit 1), and rejects it with rectangle's proof replaced by interpolation's proof (exit 101). % v12:L034 v12:L035
Comparator rejects the SiegelZeros solution with Classical.choice not permitted (Illegal axiom detected, exit 1) and with the challenge statement altered (statement mismatch, exit 1). % v12:L260

\paragraph{Statement faithfulness is by reading.}
The six statement matches rest on reading, signed off by the author, and the reasoning behind them is recorded point by point, also signed off. % v12:L002 v12:L008 v12:L145 v12:L146 v12:L204 v12:L250
The non-vacuity lemmas rule out a vacuous challenge but do not establish faithfulness. % v12:L265
The HeckeSevenEighths match rests partly on Lean lemmas (the lattice series for Re s > 1 and holomorphy off {0, 1}) and partly on reading; the six-generator identification itself is not formalized in Lean. % v12:L203

\paragraph{Sandbox.}
The primary results ran under a deny list naming all 45 address families of kernel 5.15.167.4, under which all 138 socket() calls of an all-families probe fail. % v12:L076 v12:L077
Earlier runs used a 5-family filter, which denied IP, Unix-domain, netlink and packet sockets but left AF\_VSOCK open, with a connection to the Windows host succeeding, and also left AF\_PPPOX and AF\_ALG creatable. % v12:L070 v12:L071 v12:L072 v12:L073
Three runs had no network filter: the NonVacuity lemmas, the standalone nanoda run and the statement-check build. % v12:L138 v12:L124 v12:L123
None of those three is a run where a filter affects the result. % v12:L266
