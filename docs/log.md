- Plan for src/lemma7_flint.py (Joe asked to see this before porting; he then asked me to continue unattended, so it is written here for review):
  1. Selection modulo a prime ideal. Take primes p < 2^31 with p = 1 mod 8 and (d/p) = 1, so p splits completely in K and a, b map to residues s, t mod p. Reduce rows through one embedding (a -> s, b -> t) and run the incremental echelon mod p with numpy. If a row is independent mod p, it is independent over K (rank can only drop under reduction), so retained rows are certified.
  2. Exact certification of each rejection. A row rejected mod p could still be independent over K. For each rejected row r, solve x B_S = r_S exactly over K (B = retained rows, S = pivot columns from step 1, written as a 4k x 4k rational system via the regular representation, flint fmpq_mat.solve), then check x B = r on all columns exactly. If the check fails, the row is retained and the run is flagged. This makes the selection identical to the exact greedy rule.
  3. Delta itself by CRT. For each split prime, compute det mod p at all four embeddings (a, b) -> (+-s, +-t), solve for the four coordinates of Delta mod p, and combine primes by CRT until the product exceeds twice a rigorous bound on |coordinates|. The bound comes from Hadamard's inequality at the complex embeddings, evaluated in Arb (row norms as in (5.1), with exact entries). Then N(Delta) = Delta sigma(Delta) tau(Delta) sigma-tau(Delta), computed exactly.
  4. Second method for N(Delta) (rule 6, also used routinely at N <= 4): flint fmpz_mat.det of the 4M x 4M integer matrix of the regular representation, whose determinant equals N_{K/Q}(Delta).
  5. Cross-checks: retained sets, S1, S2, Delta coordinates and N(Delta) must agree exactly with the Fraction version on all N = 2, 3 runs and on the N = 4 reference runs. The Fraction version stays the reference.
  6. New check enabled by having Delta: Lemma 7 states Delta in p^{E_p} R, which is stronger than p^{4E_p} | N(Delta). Check the p-adic valuation of the gcd of Delta's four coordinates against E_p directly. This can also be done now for the N = 3 Fraction runs, since their Delta coordinates are stored.
